# Working with maps from the original editor

Maps created before the current Map Builder remain available through YOW’s original editor.

## The how

1. Open **Atlas**.
2. Find a card marked **Original map** and open it.
3. Use the original editor’s available controls to view or continue editing the map.
4. Return with **Your atlas** when finished.
5. To start using the current tools, select **Try the new builder**.
6. Create the new map and rebuild or copy the needed information while keeping the original for reference.

📸 SCREENSHOT: Open an Atlas with an **Original map** selected. Show the original-editor notice, **Your atlas** and **Try the new builder**. Use a second current-builder map to demonstrate that both can coexist.

## The why: compatibility, not automatic conversion

YOW keeps original maps so older project data is not discarded when the Map Builder changes. Their tools and data format differ from current editable map JSON.

**Try the new builder** starts a new current-format map. It does not migrate the original map’s objects, image or layout automatically. Do not delete the original until the replacement has been checked and exported.

Current **Import map** accepts compatible editable YOW JSON, not an image export from the original editor.
