# Finalising and viewing saved draft copies

A saved finalised draft is a frozen, read-only copy of the manuscript at a chosen moment.

## The how

1. Open the manuscript tools and select **Finalise draft**.
2. Review the manuscript statistics and enter a clear draft title.
3. Select **Finalise draft** to save the copy.
4. Under **Finalised drafts**, select a saved title to open it.
5. Choose **Scroll** for continuous reading or **Pages** for a paginated reader.
6. Use the page controls to move through **Pages**.
7. Close the saved copy to return to the current manuscript.

## The why: snapshot versus live Finalised mode

The ordinary **Finalised** writing mode is a read-only view of the current manuscript. A saved finalised draft freezes the structure and text so later edits do not change that copy.

Page breaks are calculated for YOW’s reader and may differ from Word or PDF exports. Empty manuscripts can still create a copy, but the reader will state that it contains no manuscript text.

Finalised drafts are not substitutes for downloadable backups. Keep a project ZIP for restoration and a DOCX or PDF when you need an external reading copy.
