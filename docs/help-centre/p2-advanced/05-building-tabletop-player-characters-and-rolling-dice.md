# Building tabletop player characters and rolling dice

Campaign projects can use the Party room to create player-character sheets, manage the roster and roll dice.

## The how

### Create a player character

1. Open a D&D or Tabletop Campaign project.
2. Select **Party**.
3. Select the new-character control.
4. Work through the character wizard and complete the fields relevant to your system.
5. Save the character sheet.
6. Use Party search to find a character, then open the sheet to edit it.

### Roll dice

1. Open the Party dice roller.
2. Choose the die or dice expression offered.
3. Add a modifier where supported.
4. Select **Roll** and read the result and breakdown.

## The why: campaign-specific records

Party characters are tabletop sheets and are separate from ordinary narrative Character profiles, although both can support the same campaign. Use the record type that matches the information you need.

Dice results are random working aids. YOW does not enforce every tabletop system rule or verify that a modifier is legal. D&D projects may expose system-specific defaults; system-neutral campaigns avoid assuming one ruleset.

This room is available only to campaign project types and may need to be enabled in **Project Settings → Sections**.
