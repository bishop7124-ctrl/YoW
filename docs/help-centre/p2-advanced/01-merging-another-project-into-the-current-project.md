# Merging another project into the current project

Project merge copies selected worldbuilding collections from another project you own into the open destination project.

## The how

1. Back up both projects.
2. Open the project that should receive the copied records.
3. Open **Project Settings → Import**.
4. Select **Merge another project in**.
5. Choose the source project.
6. Select the supported collections you want to copy.
7. Review the summary and confirm the merge.
8. Open each affected project room and review the imported records and links.

📸 SCREENSHOT: Open **Merge another project in** with two disposable projects. Show the destination name, source selector, collection choices and review summary. Use clearly different fictional project titles.

## The why: copy, do not replace

The open project is the destination. Existing destination records remain, and selected source records are added with identifiers remapped where required. The source project remains in the Library and is not reduced or deleted.

Merge is intended for worldbuilding collections rather than replacing the destination manuscript. Links can be remapped when both linked records are included; a link to an unselected source record may not have a destination counterpart.

Repeating the same merge can create duplicates rather than synchronising changes. There is no general “unmerge” button, so use the backup if the result is broader than intended.
