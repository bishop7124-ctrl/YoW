# Managing authorised desktop devices and updates

Eligible desktop accounts can review activated devices, free device slots and install offered app updates.

## The how

### Manage devices

1. Open the desktop app and go to **Account Settings → Membership**.
2. Find **Desktop devices** and review the device count and cap.
3. Identify **This device**.
4. Select **Deactivate** beside a device you no longer use.
5. Sign in or reactivate on the intended device if a slot is now available.

### Install an update

1. When YOW offers an update, review the version information.
2. Save current work and create a backup.
3. Select **Restart to update**.
4. Reopen YOW and confirm the expected projects and version.

## The why: entitlement and software safety

Device activation limits control how many desktop installations use the account entitlement. Deactivation does not erase the remote computer’s local vault; anyone disposing of a device must also remove local data through the operating system.

Updates are checked opportunistically and may be offered at startup. If installation fails, YOW offers the update again on a later launch. Keep a project ZIP and vault snapshot before a major update.

The final Mac and Windows installer, signing and unsigned-app disclosure wording must be verified against the shipped package before this article is published.
