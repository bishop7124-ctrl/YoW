# Customising lore and schedule categories

Project Settings lets you define the category choices offered by Lore and Schedule in the current project.

## The how

1. Open the project and select **Project Settings**.
2. Open **Categories**.
3. Find the Lore or Schedule category field.
4. Enter category names as a comma-separated list.
5. Remove duplicates and leave each name clear and distinct.
6. Save the settings.
7. Open **Lore** or **Schedule** and confirm the updated category choices.

📸 SCREENSHOT: Open **Project Settings → Categories** in a disposable project. Show both comma-separated category fields, help text and save control. Use examples such as “Religion, Magic, Law” and “Drafting, Research, Play session”.

## The why: choices versus existing data

These lists control the categories offered for new and edited records. Changing a list does not necessarily rewrite existing records that already use an older value. Those records may continue to display their saved category until edited.

Use short, stable names to avoid near-duplicates such as “Politics” and “Political”. Category changes affect only the current project and do not change tags, which remain a more flexible way to add multiple labels.

If a category is widely used, filter and review its records before removing it from the configured choices.
