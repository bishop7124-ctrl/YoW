# Retiring and restoring a manuscript

Retiring stores the current manuscript and outline in a catalogue, then starts a fresh manuscript in the same project.

## The how

### Retire the current manuscript

1. Export a project backup.
2. Open the manuscript tools and select **Retired drafts**.
3. Select **Retire manuscript**.
4. Read the warning and select **Retire and start fresh**.
5. Confirm that the new manuscript is empty before beginning new work.

### Restore a retired copy

1. Return to **Retired manuscript copies**.
2. Select the saved copy.
3. Choose restore.
4. Decide whether to keep **Retire the current manuscript first** turned on.
5. Confirm and inspect both manuscript and outline after restoration.

📸 SCREENSHOT: Open **Retired manuscript copies** in a disposable project with one archived copy. Show **Retire manuscript**, the saved-copy date, download/restore controls and **Retire the current manuscript first**. Do not confirm during capture.

## The why: a project can hold successive manuscript states

Retirement preserves the full current manuscript and its outline together. It is useful for a major restart, alternate version or new campaign phase while retaining the rest of the project world.

Restoration replaces the active manuscript state. Keeping **Retire the current manuscript first** protects current work by adding it to the catalogue before the older copy becomes active. Turning that option off is riskier.

Downloadable backups remain important because catalogue copies live inside the project and account.
