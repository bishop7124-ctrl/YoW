# Creating and managing maps

The Atlas Map Builder lets you create multiple editable maps, choose their scale and visual style, and connect places to Location records.

## The how

### Create a map

1. Open the project.
2. Select **Atlas**, then **Map**.
3. Select **+ New map** or choose one of the starting-scale cards.
4. Enter a **Map name**.
5. Choose how far the map looks: a world, region, local area or interior scale as offered.
6. Choose a starter map or **Blank canvas**.
7. Choose a paper-and-ink palette.
8. Select **Create map →**.

📸 SCREENSHOT: Open the new-map dialog. Show Map name, scale choices, starter-versus-blank options, palette choices and **Create map →**. Use “The Sunken Kingdoms” as disposable example data.

### Open or rename a map

1. Return to **Atlas** from the map editor.
2. Select a map card.
3. Edit the map name in the editor’s top bar and press Enter or move focus away.

### Import an editable map

1. From **Your atlas**, select **Import map**.
2. Choose a valid YOW editable map JSON file.
3. Open the imported map and inspect it before editing.

**Import map** does not currently accept an ordinary PNG, JPEG or PDF background image.

### Delete a map

1. Open the map.
2. In the right panel, select **Delete map…**.
3. Read the warning and select **Delete map**.

Linked Locations remain in the project after the map is deleted. Export editable JSON first if the map may be needed again.

## The why: maps and their data

Each project can contain several maps. The selected scale changes the starter content and tools appropriate to the map; every starter object remains editable.

The new builder stores shapes, routes, symbols, labels, layers and linked records as editable map data. Its JSON export is the restorable/editable map format. PNG and SVG are visual exports rather than editable imports.

On phones, Map Builder opens in viewing mode. Use a tablet or desktop-sized screen for map editing. Read-only projects likewise show map viewing controls rather than the full editor.

Older maps open in the original editor. **Try the new builder** creates a new map; it should not be treated as an automatic conversion of the legacy map.
