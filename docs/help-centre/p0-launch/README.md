## Editorial notes

- Articles use UK English and current YOW UI labels.
- Screenshot placeholders contain capture instructions and safe test-data guidance.
- Cross-links are written as article titles so final Help Centre URLs can be added during publication.
- Paid checkout and packaged desktop guidance must be re-verified against the live release before publication.
- The current Map Builder imports editable YOW JSON; it does not import an ordinary image as a map background.
- Planned Series Bible export and retired project types are intentionally excluded.
