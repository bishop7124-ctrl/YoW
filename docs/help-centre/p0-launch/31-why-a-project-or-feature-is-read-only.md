# Why a project or feature is read-only

YOW disables editing when the current plan, storage mode, device or screen size does not permit changes in that area.

## The how

### Check account access

1. Open **Account Settings → Membership**.
2. Review the current plan and any downgrade or Cloud Mode notice.
3. If Free limits apply, confirm which project is the active editable project.

### Check storage mode

1. Open **Account Settings → Storage**.
2. Review whether YOW is using Cloud Sync, Local-first or Local Mode.
3. On the web, renew eligible Cloud Mode access if the account is read-only because lifetime cloud hosting has lapsed.

### Check the feature and device

- **AI Tools** is locked on Free even when the project itself is editable.
- A retained non-active Free project is view-only but exportable.
- Map editing is unavailable on phone-sized screens; use a tablet or desktop-sized screen.
- A project may be generally read-only while its export controls remain available.

## The why: protecting data and enforcing access

Free includes one editable project rather than deleting additional retained projects. View-only access lets you inspect and export those projects safely.

Lifetime cloud hosting can lapse while the desktop licence remains valid. The desktop continues in Local Mode, while web access follows the Free cloud fallback. This prevents the web app from writing into an inactive hosted workspace.

Map Builder uses a large interactive canvas and deliberately provides a viewing interface on phones. This is a device-layout limitation, not a plan lock.

If a project unexpectedly becomes read-only and none of these conditions apply, preserve an export and contact support. Include the visible notice and the device or browser being used, but do not include credentials.
