# Checking storage use and resolving a storage limit

The Storage panel shows how much cloud storage the account uses and warns before uploads are paused.

## The how

### Check storage

1. Open the account menu and select **Account Settings**.
2. Select **Storage**.
3. Review the amount used, total allowance, percentage and remaining space.

### Free storage space

1. Export important project backups first.
2. Remove unused project cover images, header banners, character portraits or location photos.
3. Replace unnecessarily large images with smaller versions where appropriate.
4. Delete only disposable projects you no longer need.
5. Return to **Storage** and refresh or wait for the figure to update after removal finishes.

### Increase the allowance

Select **Upgrade plan** when that option is available, or review current access in **Membership**.

## The why: what counts towards storage

Uploaded project media is the clearest contributor to the quota. Project data and cloud-stored writing also belong to the account, but text normally uses far less space than images.

Current allowances are:

- Free and Free cloud fallback: 250 MB
- Trial, Monthly and Lifetime: 8 GB
- Beta Tester and Founder: 15 GB

When the limit is reached, new uploads are paused until space is freed or the plan changes. Existing writing should not be deleted merely because the quota is exceeded, but cloud writes that increase storage may fail.

Replacing an image removes the superseded stored object after the new one succeeds. Removing media should reduce the authoritative storage counter after deletion settles; allow a short delay before assuming the figure is wrong.

Desktop Local Mode uses the device vault rather than a cloud quota, but the device still needs enough free disk space.
