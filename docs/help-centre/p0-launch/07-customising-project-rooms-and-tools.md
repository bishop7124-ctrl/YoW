# Customising a project’s rooms and tools

Project Settings lets you decide which planning and worldbuilding sections appear in a project without deleting their saved contents.

## The how

1. Open the project.
2. Select **Project Settings** in the project header.
3. Find **Sections**.
4. Turn individual sections on or off under **Planning**, **Characters**, **Atlas**, **Lore**, **Tabletop RPG** and **AI**.
5. Select **Done**.

To restore the recommended selection for the project type, select **Type defaults**. To show every available section, select **Enable all**.

## The why: a workspace that fits the project

Each project type begins with a recommended selection. A Novel shows the broad prose toolset; a Novella or Short Story begins lighter; campaign projects include the Party character builder; and Comic projects prioritise sequential-art planning.

These are defaults rather than permanent restrictions. You can enable Family Tree, Factions or History in a shorter project, or hide sections you do not need.

### What hiding a section does

Hiding a section removes it from the project-room navigation. It does not delete records already stored in that section. Re-enable the section to see them again.

The main **Overview** and manuscript workspace are not part of the section switches. **Character Builder** is shown as the **Party** room only for D&D and Tabletop Campaign projects.

### Access limitations

Core writing and worldbuilding sections, including Map Builder, are available on Free. **AI Tools** remains locked on Free because it uses external AI services. Enabling the section does not override that membership restriction.
