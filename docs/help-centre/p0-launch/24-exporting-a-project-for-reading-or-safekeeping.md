# Exporting a project for reading or safekeeping

YOW offers readable Word and PDF exports alongside restore-ready project backups; choose the format that matches what you need to do next.

## The how

### Export readable Word documents

1. In the Library, open the project’s **Export** menu, or open **Project Settings → Export**.
2. Select **Word docs ZIP**.
3. Wait while YOW prepares the archive.
4. Open the downloaded ZIP and check representative Word documents.

### Export a visual PDF

1. Open the project’s **Export** menu or **Project Settings → Export**.
2. Under **Visual PDF theme**, choose the preferred theme.
3. Wait for the PDF to download.
4. Open it and check the manuscript and worldbuilding sections you need.

### Create a restore-ready backup

1. Open **Project Settings**.
2. Under **Backups**, select **Create backup**.
3. Select the new backup from the list to download it.
4. Store the ZIP outside YOW.

## The why: readable export or backup?

**Word docs ZIP** contains separate readable documents for the manuscript and supported project collections. It is intended for reading, sharing or further editing in a word processor.

**Visual PDF** creates a styled, read-only World Bible-style document using the selected theme.

A project backup ZIP contains structured YOW data for **Import ZIP**. It is designed for restoration and is not intended to be read like a normal document.

### Before relying on an export

- Wait for the download to finish.
- Open the outer ZIP where applicable.
- Open representative documents or the PDF.
- Keep a restore-ready ZIP as well as any readable version.
- Store important backups somewhere independent of the browser or desktop vault.

Unaccepted tracked changes are excluded from approved exports. Map image exports are created separately inside Map Builder.
