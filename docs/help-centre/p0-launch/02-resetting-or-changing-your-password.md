# Resetting or changing your password

If you cannot remember your YOW password, you can request a secure email link and choose a new one.

## The how

### Request a reset link

1. Open the YOW login page.
2. Select **Forgot password?**.
3. Enter your account email address.
4. Select **Send reset link**.
5. Open the email from YOW and follow the reset link.

📸 SCREENSHOT: Open the **Reset password** form. Show the **Email** field, **Send reset link** and **Back to login**. Crop to the form and use a non-personal documentation address if a value is shown.

### Choose a new password

1. Follow the link in the reset email.
2. Enter a new password in **New password**.
3. Enter it again in **Confirm new password**.
4. Check that the password-requirements list is complete.
5. Select **Update password**.
6. When **Password updated** appears, select **Continue to your workspace**.

## The why: reset links and password rules

A YOW password must contain an uppercase letter, lowercase letter, number and symbol, and must be at least eight characters long. The requirements panel updates as you type. The eye buttons reveal each password field independently.

Reset links are intended for the account that requested them and may expire. If a link reports an error, return to **Forgot password?** and request another one. Use only the newest email if you requested several links.

If the two new-password fields do not match, YOW will not update the password. Your existing password continues to work until a new one is accepted.

Google sign-in users normally continue through **Continue with Google**. Changing a Google account password is handled by Google rather than YOW.

## If the email does not arrive

- Check spam or junk folders.
- Confirm that you entered the address used for YOW.
- Wait a few minutes before requesting another message.
- Contact YOW support if repeated requests do not arrive, but never share a password or reset link.
