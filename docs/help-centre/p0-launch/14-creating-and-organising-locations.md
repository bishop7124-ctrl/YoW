# Creating and organising locations

Locations store the places in your project and connect them to lore, maps and other worldbuilding records.

## The how

### Create a location

1. Open the project.
2. Select **Atlas**, then **Locations**.
3. Select **New** or **Add Location**.
4. Enter a **Name**.
5. Choose or enter a category, then add a description and tags.
6. Add a photo if wanted.
7. Select **Save**.

📸 SCREENSHOT: Open **New Location** in a disposable project. Show Photo, Name, Category, Description, Tags, **Save** and **Cancel**. Use an example such as “Glass Harbour” and a non-personal image if one is included.

### Find a location

- Use **Search** to narrow the list.
- Choose a sorting option.
- Select a category filter.
- Clear the category filter to show all locations again.

### Edit or delete a location

1. Select the location in the list.
2. Select **Edit** to change it.
3. Use the delete control and confirm when you intend to remove it.

## The why: how Locations connect

A Location is the reusable record for a place. Map elements can link to an existing Location, and a named map element can create a new Location. Lore, timeline, history and schedule records can also point to Locations.

The Location page shows records that refer to the selected place, letting you move directly to related lore and other sections. Tags and categories help organise larger atlases without changing the place’s underlying identity.

Location photos and map data contribute to storage use. Removing or replacing an uploaded image should update the storage figure after deletion finishes.

Deleting a Location does not delete map shapes or other records. A linked item may become unavailable until it is relinked to another Location.
