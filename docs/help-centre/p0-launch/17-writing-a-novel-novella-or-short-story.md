# Writing a Novel, Novella or Short Story

YOW adapts its prose workspace to the scale of the project while keeping the same connected manuscript and worldbuilding tools.

## The how

1. In the Library, select **+ Project**.
2. Choose **Novel**, **Novella** or **Short Story**.
3. Enter the title and optional description.
4. Select **Create**.
5. Open the manuscript tab and use the starter structure, or apply a template from **More → Apply a template**.
6. Add and organise scenes, then write in **Writing** mode.

## The why: differences between prose types

### Novel

- Structure: Acts → Chapters → Scenes
- Default target: 80,000 words
- Broad worldbuilding defaults, including Family Tree, Factions and History
- Best suited to long-form prose and deep connected reference material

### Novella

- Structure: Parts → Chapters → Scenes
- Default target: 30,000 words
- Lighter default room selection
- Family Tree, Factions and History remain available if enabled

### Short Story

- Structure: Parts → Sections → Scenes
- Default target: 5,000 words
- Compact defaults for a focused cast and setting
- Heavier worldbuilding sections remain optional

All three use Writing, Editing, Review and Finalised modes, scene details, notes, search, version history, templates and manuscript imports.

The default target can be changed in **Project Settings**. A target of zero removes target-based progress and allows manual progress where offered.

Choosing a shorter type does not impose a word limit. It changes guidance, labels and defaults rather than preventing a project from growing.
