# Creating and managing character profiles

Character profiles keep identity, background, goals, relationships, affiliations and images together in one connected record.

## The how

### Create a character

1. Open the project.
2. Select the **Characters** room, then the **Characters** section.
3. Select **New** or **Add Character**.
4. Enter the character’s **Name**.
5. Add any identity, affiliation, vital, biography, trait, ability or background information you need.
6. Select **Save**.

📸 SCREENSHOT: Open **Create Character** in a disposable project. Show the Identity, Affiliation, Vitals, Alias / Keywords, Portrait and Biography areas. Use a fictional example such as “Mara Venn”; crop to the form and highlight **Save**.

### Add a portrait

1. Edit the character.
2. Under **Portrait**, upload an image.
3. Use **Edit Portrait** to adjust the visible crop.
4. Save the character.

You can later edit or remove the image. Uploaded media counts towards the account’s storage allowance.

### Find and filter characters

- Use **Search** to match character information.
- Choose a sorting option.
- Filter by family group or faction.
- Select **Clear filters** to return to the full list.

### Edit or delete a character

1. Select the character in the list.
2. Select **Edit** to update the profile.
3. Use the delete control and confirm when you intend to remove the record.

## The why: connected character records

Aliases and keywords help YOW recognise references in manuscript analysis and character-focused project insights. The current-year project setting can be used when displaying age alongside birth or death information.

Character profiles can link to:

- A family group and Family Tree relationships
- A faction and membership role
- Other characters through relationship links
- Lore, timeline, history and other records that reference the character
- A character journey and its turning points

Family links and general relationship links serve different purposes. Use Family Tree for structured genealogy and the Relationship Map for broader connections such as allies, rivals or mentors.

Deleting a character can leave an unavailable reference in other records rather than deleting those records. Review linked items before removal when the character is widely used.
