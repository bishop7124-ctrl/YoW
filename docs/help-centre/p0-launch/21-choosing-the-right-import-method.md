# Choosing the right way to import existing work

YOW provides different import routes for creating a new project, appending a manuscript, restoring a backup or using AI-assisted analysis.

## The how

From the Library, open **Import ▾** and choose:

- **Manuscript Discovery** to create a complete project from DOCX, TXT or Markdown using local, non-AI analysis and a review step.
- **AI Import** to analyse TXT, Markdown, DOCX, PDF or ZIP writing files with your configured AI provider and review proposed records.
- **Import ZIP** to restore a native YOW backup or compatible structured project archive.

From an open manuscript, use **More → Import a document** to append the detected structure and text from a DOCX file to the existing manuscript.

From **Project Settings → Import**, use **Merge another project in** to copy selected collections from another project you own.

## The why: which option should I use?

### I have a manuscript and want a new project

Use **Manuscript Discovery** when you want processing to stay local and are prepared to review candidate characters, locations, factions and lore. Use **AI Import** when you want provider-assisted interpretation.

### I have a DOCX and an existing project

Use **Import a document** from the manuscript menu. The detected structure is appended; it does not replace existing acts, chapters or scenes.

### I have a YOW backup

Use **Import ZIP**. Native backups preserve structured project data and are the preferred restoration route.

### I want to combine two projects already in my Library

Use **Merge another project in**. It copies selected content into the current project without removing its existing records.

## Important limitations

- Read the preview before creating or appending records.
- Importing the same archive twice creates another imported copy with fresh record identifiers; it does not update the first import in place.
- Ordinary PDF and writing-file ZIP imports may require AI; a native YOW ZIP does not.
- Map JSON uses **Atlas → Import map**, not the project import menu.
- Export or back up an important destination project before a large append or merge.
