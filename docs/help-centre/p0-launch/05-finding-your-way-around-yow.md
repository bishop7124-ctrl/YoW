# Finding your way around YOW

YOW separates your overall Library, each project’s planning rooms, and its focused writing workspace so you can move between them without losing your place.

## The how

### Open a project

1. Sign in to reach the **Library**.
2. Select a project card, or select **Open Project** on the featured project.
3. YOW opens the project **Overview**.

### Move between project rooms

1. Use the room bar to choose **Overview**, **Planning**, **Characters**, **Atlas**, **Lore**, **Party** or **AI Tools**.
2. If a room contains several sections, use its section tabs—for example **Characters**, **Relationship Map**, **Family Tree** and **Factions**.
3. Select the manuscript tab—labelled for the project type—to enter the writing workspace.

### Return to the Library or project

- From a planning room, use the YOW/project navigation at the top of the workspace to return to the Library.
- From the manuscript workspace, select **Project** in the top bar to return to the project.
- Browser back and forward navigation also preserve supported project and scene URLs.

### Open settings, help or account controls

- Select **Project Settings** in the project header for project details, rooms, exports, backups, merging and categories.
- Open the account menu in the top-right corner for **Account Settings**, **Help & Contact**, **About**, **Legal** and **Sign Out**.

## The why: Library, project and manuscript

The **Library** is the home for all projects and series. It provides project status, grouping, the focus project, import and creation controls.

The project **Overview** summarises one project’s writing, structure and worldbuilding. Project rooms hold connected records such as characters, locations, lore, ideas and history.

The manuscript workspace is designed for sustained writing. Its own rail, editor modes, inspector, reference catalogue, search and AI panel remain separate from the planning-room navigation.

Some rooms may be absent because they are hidden in **Project Settings**. The **Party** room appears only for D&D and Tabletop Campaign projects. **AI Tools** is locked on Free accounts.

On narrow screens, navigation may collapse into compact tabs or menus. Map editing is view-only on phones, although maps remain viewable and linked Locations can still be opened.
