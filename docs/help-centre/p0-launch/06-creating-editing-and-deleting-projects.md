# Creating, editing and deleting projects

You can manage project details from the Library and use the full **Project Settings** screen after opening a project.

## The how

### Create a project

1. In the Library, select **+ Project**.
2. Enter a title and optional description.
3. Choose a series or keep the project **Standalone**.
4. Select a project type.
5. Select **Create**.

### Edit a project from the Library

1. Find the project card or featured project.
2. Open its settings control.
3. Change its title, description, series, status, focus setting, visibility of later series works or tags as available.
4. Select **Save**.

### Edit an open project

1. Open the project.
2. Select **Project Settings** in the project header.
3. Change the title, description, target, status, current year, cover, banner, rooms, categories or other settings.
4. Select **Done**.

### Delete a project

1. Open the project’s edit panel from the Library.
2. Select **Delete project**.
3. Confirm the deletion when prompted.

Create or download a backup before deleting a project you may need again.

## The why: settings and project data

Library editing is intended for high-level organisation. The open-project settings contain the broader controls that affect the project workspace, exports and local backup configuration.

Changing the project title, description, status, targets or images does not alter manuscript text or worldbuilding records. Hiding a room also leaves its records intact.

Removing a project from a series does not delete it; it returns to the Library as a standalone project. Deleting an entire series likewise leaves its projects in the Library. Deleting a project is different: it removes the project and its contained records.

### Before deleting

- Export a restore-ready ZIP backup.
- Check that the download finished.
- Keep the backup somewhere outside the browser or desktop vault.
- If the project is in a series, remember that deleting it may affect series continuity views.
