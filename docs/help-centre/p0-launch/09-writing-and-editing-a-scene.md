# Writing and editing a scene

The manuscript editor gives each scene—or encounter, page or other project-specific unit—its own writing surface, status and supporting details.

## The how

1. Open the project’s manuscript workspace.
2. Select a scene in the structure rail.
3. Select **Writing** in the top bar for direct drafting.
4. Click the writing area and enter your text.
5. Use the scene header or **Inspector** to rename the scene, change its status and add POV, location or summary details.
6. Wait for the save indicator to show **Saved** before closing the tab immediately after a change.

### Format text

- Select text and use **B**, *I* or underline from the editor toolbar.
- Use **Prose** for normal paragraphs or **Bullets** for one item per line.
- Use Undo and Redo in the toolbar or standard keyboard shortcuts.
- Select **Copy** to copy the full scene reliably, including very long scenes.

### Add a note

1. Place the cursor where the note belongs.
2. Select **Add note** or the contextual **Note** action.
3. Enter a note title and text.
4. Select **Save**.

## The why: scene content and metadata

Scene prose is saved separately from lightweight scene details so YOW can keep large manuscripts responsive. The user-facing result is still one scene: its text, title, status, notes and Inspector details travel together in project exports and backups where supported.

Statuses cycle through Draft, Writing, Complete and Revision. They help the manuscript rail and project analytics show progress; changing a status does not lock the scene.

The Inspector’s POV, location and summary fields are reference information. They do not automatically rewrite or tag the prose. Linked names detected in text may be opened in the side panel when a matching project record exists.

### Save indicators

- **Saving…** means YOW is still writing a recent change.
- **Saved** means current changes have been stored by the active storage mode.
- A save error means the latest change could not be stored on the device; keep the tab open while YOW retries and preserve a copy of the prose if the warning continues.
