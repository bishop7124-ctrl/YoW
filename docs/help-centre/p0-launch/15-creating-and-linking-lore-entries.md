# Creating and linking lore entries

The Lore notebook stores rules, histories, cultures, magic systems and other facts, with links to the people and places they affect.

## The how

### Create a lore entry

1. Open the project.
2. Select **Lore**, then the **Lore** section.
3. Select **New** or **New Lore Entry**.
4. Enter a **Title**.
5. Choose or enter a category.
6. Add tags and write the entry’s content.
7. Select any linked characters, locations or related lore.
8. Select **Save Entry**.

📸 SCREENSHOT: Open **New Lore Entry** in a disposable project. Show Title, Category, Tags, Content, Linked Characters, Linked Locations, Related Lore and **Save Entry**. Use a fictional entry such as “The Binding Laws”.

### Find related lore

- Search from the notebook list.
- Filter by category or tag.
- Sort the results.
- Select a tag on an open entry to filter by that tag.
- Follow **Related Lore**, **Linked Characters** or **Linked Locations** to open connected records.

### Edit or delete an entry

1. Select the entry.
2. Select **Edit** and save the changes.
3. To remove it, select the delete control and confirm.

## The why: explicit and inferred connections

Explicit links record a deliberate relationship between the lore entry and another record. Related-by-tag suggestions help discover entries that share vocabulary but do not create a formal link by themselves.

Related Lore can be navigated in either direction: an entry shows lore it links to and lore that references it. This is useful for breaking a large subject into smaller records without losing context.

Categories are project-specific and can be edited in **Project Settings → Categories**. Changing the available category list does not rewrite labels already stored on existing entries.

Deleting a linked character, location or lore entry does not delete the current lore entry. Its missing reference may remain visible as unavailable until edited.
