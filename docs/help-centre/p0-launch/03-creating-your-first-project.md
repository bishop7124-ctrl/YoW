# Creating your first project

Your first project creates a workspace for your manuscript, planning and connected worldbuilding records.

## The how

### Start with the welcome wizard

1. Sign in to YOW for the first time.
2. Choose **Start with the sample world** to explore prepared content, or **Create a blank project** to begin your own.
3. For a blank project, choose the kind of work you are creating.
4. Enter a project title.
5. Enter a word target, or a session target for a campaign project, if wanted.
6. Review the project summary and select **Create Project**.

You can select **Skip for now** and create a project later from the Library.

### Create a project from the Library

1. Open the Library.
2. Select **+ Project**.
3. Enter a **Title** and optional **Description**.
4. If you already have a series, choose it under **Series** or keep **Standalone**.
5. Select one of the six project types.
6. Select **Create**.

## The why: what YOW creates

YOW creates a starter structure suited to the chosen format. For example, a Novel begins with an act, chapter and opening scene, while a campaign begins with an arc, session and encounter. A Comic uses volumes, issues, pages and panels.

Each project type also starts with a recommended set of project rooms. These defaults do not permanently restrict the project: most rooms can be enabled or hidden later in **Project Settings**.

The title, description, target, status, images and series assignment can be changed later. The project type itself is chosen when the project is created and is not offered as an editable field afterwards.

### Sample world or blank project?

The sample world is useful for seeing how connected records look when populated. A blank project is better when you already know what you want to build. Sample content belongs to its own project and does not alter a project you create later.

### Free-plan note

Free provides one editable project. If your account already retains several projects after a plan change, YOW asks you to choose which one remains editable.
