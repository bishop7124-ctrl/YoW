# Creating a project from an existing manuscript

Manuscript Discovery creates a new YOW project from a DOCX, TXT or Markdown manuscript using local, non-AI analysis and lets you review every proposed record first.

## The how

1. In the Library, select **Import ▾ → Manuscript Discovery**.
2. Select **Choose a manuscript**.
3. Choose a DOCX, TXT, MD or Markdown file.
4. Review the summary of detected structure and candidate records.
5. Enter the **Project title** and choose the **Project type**.
6. Select **Review project findings**.
7. Work through the categories and select only the records you want.
8. Rename candidates, review aliases, change a candidate’s category, merge duplicates, or choose how to handle an existing match.
9. Select **Create project**.
10. When **Project created** appears, select **Open project**.

## The why: candidates, not facts

Discovery looks for document headings, scene breaks, repeated names and relationship-like language. It proposes records but does not create them until you finish review.

Possible aliases are not merged automatically. Select an alias only when it refers to the same character or place. Likewise, use **Merge candidate** when two proposed entries are genuinely the same record.

When a matching record is detected, the available actions can include:

- **Keep existing unchanged**
- **Fill blank fields**
- **Create separately**

### Structure detection

DOCX headings are used as structural signals, while scene-break markers can create scenes. Word processors sometimes apply heading styles to ordinary paragraphs; inspect the detected act, chapter and scene counts before creating the project.

TXT and Markdown files have less formatting information, so headings and consistent separators improve the result. The source file is read for the import; YOW does not change it.
