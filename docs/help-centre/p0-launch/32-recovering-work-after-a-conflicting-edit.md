# Recovering work after a conflicting edit

YOW provides different recovery tools depending on whether the conflict affected one scene, proposed revisions, cloud synchronisation or an entire project.

## The how

### A scene was edited in two tabs

1. Select the manuscript’s **conflict copy** warning.
2. Compare the current scene with the preserved copy.
3. Copy any passages needed from both versions to a safe temporary document.
4. Select **Restore** or **Discard**.
5. Combine text in one remaining tab and wait for **Saved**.

### Tracked changes need review

1. Select **Review**.
2. Move through changes with **Previous** and **Next**.
3. Accept or reject each change, or handle a whole scene.

### An earlier saved scene is needed

1. Open **Version history**.
2. Preview the required version.
3. Select **Restore this version**.

### Desktop and cloud contain different work

1. Open **Account Settings → Storage**.
2. Start the appropriate resume or manual sync action.
3. Review the preview and every surfaced conflict.
4. Choose which version to keep for each conflict.
5. Confirm the merge and wait for Cloud Sync to resume.

## The why: choose the narrowest recovery tool

Use scene conflict review for simultaneous edits, Review mode for intentional tracked revisions, version history for an earlier scene state, a project ZIP for whole-project restoration, and a desktop snapshot only for whole-vault recovery.

Avoid restoring a whole project or vault when only one paragraph is missing. Broad restoration can replace newer unrelated work.

Before any irreversible decision:

- Copy valuable text from both sides.
- Export the current project if it is readable.
- Confirm which device or tab contains the newest intended work.
- Keep only one editing tab open after resolution.
