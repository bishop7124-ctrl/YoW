# Choosing the editable project on Free

When Free limits apply to an account with several retained projects, YOW asks you to choose the one project that remains fully editable.

## The how

1. When **Choose your active project** appears, select each project carefully and identify the one you want to continue editing.
2. Select that project’s radio option.
3. If you have not already done so, select **Download all project backups** and verify the download.
4. Select **Confirm active project**.

## The why: what the choice changes

The selected project remains editable with YOW’s core writing and worldbuilding toolkit. The other retained projects become view-only: you can open and export them, but editing controls are disabled.

Choosing the active project does not delete the others. Free cloud storage is 250 MB across the account, so export backups before removing projects or media to fit the allowance.

### Choose carefully

The current interface warns that the active-project choice cannot be changed while remaining on Free. Upgrading unlocks editing for the retained projects again.

Consider:

- Which project you are actively writing
- Whether another project needs edits before a deadline
- Which projects already have current external backups
- Whether important series continuity depends on editing several projects

A project inherited from a previous Monthly subscription may be locked according to the account’s downgrade state. The Membership tab explains the current access shown by YOW.
