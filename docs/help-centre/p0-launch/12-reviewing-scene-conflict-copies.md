# Reviewing scene conflict copies

When the same scene is edited in two browser tabs at once, YOW keeps the competing text as a conflict copy instead of silently overwriting it.

## The how

1. Look for the warning in the manuscript top bar, such as **1 conflict copy**.
2. Select the warning to open conflict review.
3. Read the current scene and preserved conflict copy.
4. Choose **Restore** to make the conflict copy the scene’s current text, or **Discard** when the current scene is the version you want.
5. Confirm the action if asked.
6. Wait for **Saved** before closing the remaining tab.

## The why: why conflict copies appear

YOW uses revision checks so that a later save from an out-of-date tab cannot silently replace newer scene text. When it detects competing revisions, it preserves both and asks you to decide.

Conflict copies are most likely when:

- The same scene is open in two tabs or windows.
- A computer wakes with an old tab that later saves.
- Two devices edit before the latest cloud changes arrive.

### Restore or discard?

Choose **Restore** when the preserved copy contains the work you want to continue from. Choose **Discard** only after confirming that the current scene already contains everything needed.

If both versions contain useful passages, copy the required text to a safe temporary document before choosing one, then combine it in the manuscript afterwards.

Avoid continuing to edit the same scene in multiple tabs. Close or refresh the older tab once the conflict is resolved.
