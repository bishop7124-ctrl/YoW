# Exporting all account projects before a plan change or deletion

**Export all projects** creates one download containing every project you own, either as restore-ready backups or readable Word documents.

## The how

1. Open the account menu and select **Account Settings**.
2. Select **Storage**.
3. Find **Export all projects**.
4. Choose **Export all as ZIP backups** for restoration, or **Export all as Word docs ZIP** for readable documents.
5. Keep YOW open while the progress count advances.
6. Wait for the success message and completed browser download.
7. Open the outer ZIP and confirm that every expected project has its own folder.

📸 SCREENSHOT: Open **Account Settings → Storage** in a disposable multi-project account. Show **Export all projects**, both export buttons and the explanatory text. Crop out account identifiers and use non-personal project names.

## The why: one download, several projects

Browser download restrictions can make one-download-per-project unreliable. YOW therefore builds a single outer ZIP containing a folder for each project.

**ZIP backups** places an independently restorable YOW backup in each project folder. **Word docs ZIP** places readable category documents for each project in the combined download.

For the strongest safety before deletion or a plan change, create the backup version first. A readable document is valuable for inspection but does not preserve every structured link needed for restoration.

### Verify the archive

- Check the number of top-level project folders.
- Confirm that projects with the same title have separate collision-safe folders.
- Open at least one inner ZIP or representative Word document from each important project.
- Move the completed archive to a safe location outside YOW.
- Do not continue with account deletion if the export reports a failed project.

The export reports partial success when some projects succeed and others fail. Retry or export failed projects individually before relying on the archive.
