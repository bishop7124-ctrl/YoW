# Contacting support and sending feedback

Use **Help & Contact** to ask for assistance or send a product suggestion from inside YOW.

## The how

### Send a support request

1. Open the account menu.
2. Select **Help & Contact**.
3. Select the **Support** tab.
4. Enter your first name if wanted.
5. Describe the problem in **Message**.
6. Select **Send message**.
7. Wait for **Message received** before closing the panel.

Your signed-in email address is added automatically and cannot be edited in this form.

### Send a suggestion

1. Open **Help & Contact**.
2. Select **Suggestions**.
3. Enter a short feature title.
4. Choose a category.
5. Explain what should change and how it would help your workflow.
6. Select **Send request**.

## The why: information that helps support

Include:

- The page or project room where the problem occurred
- The button or action used
- The exact visible error wording
- Whether you are using web or desktop
- Browser and device type where relevant
- Whether the project is editable, view-only, Cloud Sync, Local-first or Local Mode
- Whether the problem happens again in a disposable test project

Do not include passwords, confirmation links, reset links, API keys, payment-card information, private authentication tokens or an unpublished manuscript unless support specifically provides an approved secure route.

For a possible data-loss issue, keep the affected tab or desktop app open, copy visible unsaved prose to a local document and avoid repeated imports, syncs or restores until the current state has been described.

Suggestions can be categorised as a new feature, improvement, AI assistant, accessibility, export/import, mobile experience or other request. Submitting a suggestion does not promise that it will be implemented or provide a delivery date.
