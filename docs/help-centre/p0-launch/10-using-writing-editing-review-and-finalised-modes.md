# Using Writing, Editing, Review and Finalised modes

The manuscript top bar separates direct drafting, proposed revisions, change review and finished reading views.

## The how

### Write directly

1. Select **Writing**.
2. Choose a scene and edit its text.
3. Changes become the current manuscript text when saved.

### Propose tracked changes

1. Select **Editing**.
2. Edit the manuscript.
3. YOW records insertions and deletions as proposed changes rather than immediately making them final.
4. Switch to **Review** when you are ready to decide what to keep.

### Review changes

1. Select **Review**.
2. Use **Previous** and **Next** to move through proposed changes.
3. Select **Accept change** or **Reject change**.
4. Use **Accept all in scene** or **Reject all in scene** when the whole scene can be handled together.

📸 SCREENSHOT: In a disposable manuscript, create one short insertion and deletion in **Editing**, then open **Review**. Show the redlined document, change navigator and accept/reject controls. Use fictional text and highlight the review controls.

### Read the finished manuscript

1. Select **Finalised**.
2. Choose **Manuscript** for continuous reading or **Book** for a page-style preview.
3. Use **Export** when you need a document copy.

## The why: protecting the approved text

**Writing** changes the manuscript directly. **Editing** is for revisions that should remain proposals until reviewed. Unaccepted Editing-mode prose is kept out of exports and finalised copies so a suggestion cannot quietly become the approved manuscript.

If you try to leave Editing with unreviewed proposals, YOW directs you towards Review rather than discarding the work. Review can be completed one change or one scene at a time.

**Finalised** is a reading and export view; it is not where you edit prose. A separately named finalised draft copy can be saved from the manuscript menu where that control is available.

Comic projects use their dedicated page-and-panel planner instead of these prose manuscript modes.
