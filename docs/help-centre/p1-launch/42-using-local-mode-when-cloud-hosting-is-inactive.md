# Using Local Mode when cloud hosting is inactive

Local Mode keeps eligible desktop writing editable in the device vault when Cloud Mode hosting is inactive.

## The how

1. Open the YOW desktop app on the device that holds the local work.
2. Open **Account Settings → Storage** and confirm **Local Mode is active**.
3. Continue editing local projects normally.
4. Use project ZIP exports to move or back up work; automatic and manual cloud upload/download are unavailable while hosting is inactive.
5. On the web, expect Free cloud limits, including one editable project and the Free storage allowance.
6. Renew Cloud Mode from **Membership** when available.
7. Return to Storage, review differences and resolve conflicts before Cloud Sync resumes.

📸 SCREENSHOT: In the desktop release candidate with a lapsed disposable Lifetime fixture, show the **Local Mode is active** banner, unavailable sync controls and export access. Do not use a real customer account.

## The why: licence, local work and hosting

A Lifetime desktop licence and Cloud Mode hosting are separate entitlements. Hosting lapse pauses cloud writes; it does not delete local projects or remove the ability to export from the desktop app.

Work created locally can diverge from the last cloud copy. Renewal therefore uses reconciliation rather than silently overwriting one side. Back up the local project and create a vault snapshot before resolving a large difference.

Local Mode protects availability, not the physical device. Keep operating-system disk encryption enabled and maintain backups outside the computer.
