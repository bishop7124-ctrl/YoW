# Sharing worldbuilding records across a series

Series sharing makes selected categories from earlier projects visible in later projects while protecting story order.

## The how

1. In the **Library**, open **Edit series**.
2. In the sharing area, enable the categories you want pooled across the series.
3. Confirm the project order and save.
4. Open a later project to view inherited entries in the enabled rooms.
5. If an earlier project must see later-work records, edit that project and enable **Include later works**.

When deleting a shared record, read whether YOW offers **Delete from this project** or **Delete from all synced projects** before confirming.

## The why: continuity without automatic spoilers

By default, data flows forward. Book three can draw on shared records from books one and two, while book one is protected from later developments. **Include later works** deliberately relaxes that rule for the selected project.

Sharing visibility does not turn projects into independent duplicates. Editing a shared source record can affect how it appears elsewhere in the series, so confirm which project owns the entry before making a continuity change.

Only supported, enabled categories participate. Manuscript prose is not pooled as a general series record.
