# Creating and managing a series

A series groups related projects, records their order and can share selected worldbuilding categories forward through the sequence.

## The how

### Create a series

1. Open the **Library** and select **New Series**.
2. Enter a name and create it.
3. Open **Edit series** to add a summary, status, tags, cover image and word goal where available.
4. Add existing projects or create a new project in the series.
5. Reorder projects into story order and save.

### Remove or delete

Use the remove control beside a project to take it out of the series. Select **Delete series** to remove the series record; confirm the warning. The projects themselves are not deleted.

## The why: grouping plus continuity

Story order is important because shared data flows forward: later projects can see eligible records from earlier work. Reordering can therefore change which inherited entries are available.

Removing a project clears its series membership but keeps its manuscript and project records. Deleting the series also leaves its projects in the Library as standalone work.

Series cover media counts towards storage. A downloadable Series Bible is not currently available, even if the dashboard mentions it as future work.
