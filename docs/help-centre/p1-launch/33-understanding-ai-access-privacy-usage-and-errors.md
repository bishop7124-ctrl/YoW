# Understanding AI access, privacy, usage and errors

YOW’s AI features use your chosen provider and model, while YOW controls which selected project context is prepared for a request.

## The how

Before using AI:

1. Confirm that your access level includes **AI Tools**.
2. Open **Account Settings → AI** and connect a supported provider.
3. Review the provider’s billing and privacy terms.
4. Choose the model and decide whether to sync AI settings across devices.

For each request, review the chosen context and any token or estimated-cost information shown. Stop or retry only after reading the error.

📸 SCREENSHOT: Open an AI feature’s context/usage notice with a documentation account. Show token or cost information, selected context and provider/model name. Mask the key and use disposable project data.

## The why: where data and cost go

Free access does not include AI Tools. YOW uses a bring-your-own-provider model: provider availability, limits and charges belong to the provider account. Model catalogues can change, so use the current selector rather than a static model list.

Prompts can include the text you enter plus selected manuscript or worldbuilding context. Do not send material you are unwilling to share with that provider. API keys are hidden after saving; replacing a key requires entering a new value.

Context and output limits mean a model may receive only part of a large manuscript. Estimates are not invoices. Invalid keys, missing provider billing, rate limits, unavailable models, connection loss and provider safety rules can all cause errors without deleting project content.
