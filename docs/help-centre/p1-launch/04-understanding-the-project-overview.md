# Understanding the project Overview

The **Overview** turns saved project information into progress, activity and worldbuilding summaries.

## The how

1. Open a project and select **Overview**.
2. Use **Continue writing** to return to the manuscript, or **Project settings** to edit the workspace.
3. Switch between the standard overview and **Insights** where available.
4. Select a quick-link card such as **Outline**, **Characters**, **Atlas**, **Lore**, **Timeline & History** or **Ideas**.
5. Select a listed scene or item to open it when the card supports navigation.

## The why: how the summaries are calculated

The main view combines writing progress, recent activity, a goal streak, manuscript shape and worldbuilding totals. Campaign projects replace word-oriented progress with campaign and session measures where appropriate.

**Insights** interprets saved records rather than judging the quality of the work:

- **Readability** estimates sentence and syllable patterns and can be distorted by dialogue, invented names or script-like text.
- **Scene health** groups scenes by length to reveal empty, unusually short or unusually long items.
- **Draft balance** compares words across the top-level structure.
- **Worldbuilding coverage** looks for saved names, keywords and explicit links.
- **Character focus** counts words in scenes where a character’s saved name or keywords appear.

Activity and streak figures depend on recorded scene history. Imported text or work created before history was recorded may produce sparse charts. Treat Overview as a navigation and pattern-finding tool, not an assessment score.
