# Converting an idea into a project record

Conversion creates a supported project record from an idea and links the two so the original thought remains traceable.

## The how

1. Open **Ideas** and select an existing idea.
2. Select **Save & Convert**.
3. In **Convert to Story Entity**, choose an available destination such as character, location, lore or event.
4. Enter the new **Entity name**.
5. Select **Convert & Link**.
6. Open the new record in its project room and add its detailed fields.

If creation succeeds but the link does not, use **Retry link** rather than creating another entity.

📸 SCREENSHOT: Open **Convert to Story Entity** for a disposable idea. Show several enabled destination types, the **Entity name** field and **Convert & Link**. Use “The Lantern Keeper” as fictional sample data.

## The why: conversion is a starting point

Conversion preserves the idea and creates a separate structured record. It does not attempt to distribute every sentence into specialist fields, so review the new profile afterwards.

Only destinations whose project sections are enabled are offered. If the type you need is missing, check **Project Settings → Sections**. A retry after a linking failure is designed to connect the entity that was already created rather than make a duplicate.

Deleting the source idea later does not necessarily delete the converted record. Treat them as connected but independently editable items.
