# Creating a custom project calendar

Calendar settings let the Schedule use your world’s month names, month lengths and week structure.

## The how

1. Open **Schedule** and select **Calendar settings**.
2. Choose the **Opening view** behaviour and, when using a fixed position, its default month and year.
3. Rename months and set the number of days in each.
4. Select **Add month** or remove a month where allowed.
5. Set **Days per week** and edit each day label.
6. Select **Save calendar**.

Use **Reset to default** to restore YOW’s standard calendar after reading the confirmation.

## The why: dates belong to the project

The custom calendar defines how Schedule dates are displayed and validated. It applies to that project rather than changing your computer calendar.

Opening at a fixed month and year creates a consistent starting point. The alternative last-viewed behaviour returns you to the calendar position used most recently. Month and week limits protect the calendar layout; the form prevents removing every month.

Changing a calendar after creating events can change how stored date positions are interpreted or displayed. Export or back up an important project before a major calendar redesign, then review existing events after saving.
