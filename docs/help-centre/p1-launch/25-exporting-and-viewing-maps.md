# Exporting and viewing maps

Maps can be exported as images for sharing or editable JSON for safekeeping and re-import.

## The how

1. Open **Atlas** and select a map.
2. Open **Export ↓**.
3. Choose:

   - **PNG image** for a standard bitmap image
   - **SVG image** for a scalable vector image
   - **Editable map JSON** for a YOW-editable copy

4. Save the downloaded file and open it to confirm the result.
5. Use **Expand canvas** for a larger editing/viewing area, and the zoom controls or **Fit** to frame the map.

On a phone, use the available viewing and zoom controls. Move to a tablet or computer for full editing when YOW presents the map as read-only.

📸 SCREENSHOT: Open a finished disposable map and expand **Export ↓**. Show all three formats, **Expand canvas**, zoom percentage and **Fit**. Avoid browser download notifications that reveal local filenames.

## The why: choose a format by purpose

PNG is widely supported and suitable for documents or sharing. SVG preserves crisp vector lines at different sizes. Neither image format can be imported back as editable Map Builder objects.

JSON preserves objects, styles, grid settings and editable structure. Use **Atlas → Import map** to restore it. It is map data, not a full project backup.

Phone viewing is intentionally safer and less crowded than the full editor. A read-only phone map does not mean the project itself is read-only.
