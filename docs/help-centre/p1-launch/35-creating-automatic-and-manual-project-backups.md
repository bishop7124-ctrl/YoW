# Creating automatic and manual project backups

Project backups are restore-ready ZIP snapshots containing structured project data, settings and included media.

## The how

1. Open the project’s **Project Settings**.
2. Open **Export** and find **Backups**.
3. Choose the automatic backup frequency offered for the project.
4. Select **Create backup** for an immediate manual snapshot.
5. Use **Download** beside a stored backup to save a local copy.
6. Use **Import ZIP** from the Library when you need to restore that file.

Open Project Settings periodically so YOW can perform any due automatic backup check tied to that workflow.

📸 SCREENSHOT: Open **Project Settings → Export → Backups** for a disposable project. Show frequency, retention explanation, one automatic and one manual backup, **Create backup** and **Download**.

## The why: stored snapshots and downloaded copies

Automatic backups follow their configured schedule and retain a limited recent set; older automatic copies are replaced as new ones are created. Manual backups are separate and are kept according to the behaviour described in the panel.

A stored backup still belongs to the YOW environment. Download important copies to storage you control, especially before a downgrade, large import, structural reorganisation or account deletion.

Backups are designed for restoration, unlike Word or PDF exports. Importing a backup creates or merges records according to the chosen Import ZIP route and remaps identifiers where required.
