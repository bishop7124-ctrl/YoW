# Starting an AI chat with project context

AI chat can discuss the open project using the behaviour, creative freedom and context scope you choose.

## The how

1. Configure a provider in **Account Settings → AI**.
2. Open a project and select the AI chat area.
3. Choose a behaviour or working mode.
4. Set the creative-freedom and project-context controls.
5. Add custom instructions when needed.
6. Enter a message and send it.
7. Use the response controls to retry, copy or save useful material into a supported project record.
8. Open conversation history to resume or delete an earlier chat.

📸 SCREENSHOT: Open a new AI chat in a disposable project. Show behaviour, creative freedom, context scope, custom instructions and the empty message field. Never display an API key or private manuscript.

## The why: context is chosen, not unlimited

Project context helps the model refer to saved characters, places, lore and manuscript material. The exact content sent depends on the selected scope and size limits; a large project may be summarised or only partly included.

Behaviour and creative freedom shape the request but do not guarantee factual accuracy. Treat responses as suggestions and verify them against the project. Saving a response creates or updates the chosen YOW record only after you confirm the action.

Conversation history is project work, whereas provider billing and retention are governed by the provider account connected in Settings.
