# Using the pacing chart and Book view

The pacing chart compares scene or chapter length, while **Book** view presents the current manuscript as a page-style reading preview.

## The how

### Open the pacing chart

1. Open the manuscript tools menu.
2. Select **Pacing chart**.
3. Switch between **Scenes** and **Chapters**.
4. Review the average, shortest, longest and outlier summaries.
5. Select a bar or listed outlier to open that part of the manuscript.

### Open Book view

1. Switch the manuscript to **Finalised** mode.
2. Select **Book**.
3. Use the previous and next page buttons to move through the preview.
4. Return to **Manuscript** for the continuous read view.

📸 SCREENSHOT: Open **Pacing Chart** for a disposable Novel with scenes of varied length. Show **Scenes/Chapters**, the bar chart, summary figures and at least one outlier. A second capture may show **Finalised → Book** with a two-page spread.

## The why: two different reading tools

The pacing chart measures word count, not dramatic quality. A long scene can be intentional and a short scene can be effective; the chart helps you find sections worth reviewing. Empty structure and unassigned scenes can make the chapter view sparse.

**Book** view is a visual preview of the current finalised read view. It skips empty chapters and includes written scenes in manuscript order. Page breaks are calculated for the screen and are not a promise that DOCX or PDF exports will paginate identically.

Saved finalised copies have their own **Scroll** and **Pages** reader. That snapshot is separate from the live **Finalised → Book** view.
