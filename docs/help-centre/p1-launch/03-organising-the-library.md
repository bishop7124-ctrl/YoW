# Organising the Library

The Library gathers projects and series, keeps one project in focus and provides different ways to group work.

## The how

1. Open the **Library** from the YOW navigation.
2. Use **Group by** to arrange project cards by **Series**, **Status** or **Type**.
3. Select a project card to open it.
4. Use the card controls to mark or clear the **Focus project**, edit the project or export it.
5. Use the status queue filters and sorting controls to find work by status, series, title or progress.

To change a project’s group, edit its status, type or series assignment. Grouping changes the Library view; it does not move or duplicate project data.

## The why: focus, groups and queues

The **Focus project** is the project YOW places most prominently so you can continue quickly. It remains an ordinary project and can be changed without affecting its content.

Grouping by **Series** separates series books from standalone projects. **Status** is useful for a mixed pipeline such as planning, drafting and complete work. **Type** is helpful when the Library contains prose, campaigns and comics.

The status queue is a filtered working list rather than a second copy of the Library. Its sorting and series filter help answer questions such as “what am I drafting now?” or “which project is furthest from its target?”.

On Free, retained projects may remain visible but read-only. Library organisation and exports remain useful even when only one project is editable.
