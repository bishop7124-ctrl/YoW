# Troubleshooting maps on phones, tablets and older projects

Map behaviour can differ by device size, input method and whether the map was created in the original or current builder.

## The how

1. Open **Atlas** and identify whether the card says **Original map**.
2. On phones, use viewing, pan and zoom controls; move to a tablet or computer if editing controls are unavailable.
3. On touch devices, use the visible tool controls rather than relying on desktop keyboard shortcuts.
4. For an original map, continue editing in the original editor or select **Try the new builder** to start a new map.
5. For JSON import errors, confirm the file came from **Editable map JSON** in the current builder.
6. Export important maps before deleting or rebuilding them.

## The why: responsive viewing and two map formats

The current builder has dense drawing and property controls, so narrow phones may provide viewing rather than full editing. This is a device limitation, not a project lock.

Original maps remain available through their original editor. **Try the new builder** begins a new current-format map; it does not promise to convert every original object. Keep the original until the new version is complete.

The import control accepts compatible editable JSON, not an ordinary PNG, JPG or SVG image. Image exports are for viewing and sharing.
