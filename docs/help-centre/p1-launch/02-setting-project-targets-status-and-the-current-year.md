# Setting project targets, status and the current year

Targets and statuses help you measure progress; the current year gives age-sensitive worldbuilding records a shared reference point.

## The how

### Change a project target or status

1. In the **Library**, open the project card menu and choose **Edit project**.
2. Choose a **Status**.
3. For prose and comic projects, enter a **Word target**. For campaign projects, enter a **Session target**.
4. If offered, update manual progress.
5. Select **Save changes**.

You can also change writing targets from the project **Overview** or the manuscript **Inspector → Progress**.

### Set the current year

1. Open a project.
2. Open the project control that displays the current year.
3. Enter the year that represents “now” in this project and save it.

## The why: what each value affects

**Status** organises the Library and its status queue; it does not lock the project or change manuscript scene statuses. **Word target** compares the manuscript word total with the project goal. **Session target** compares planned campaign sessions with the campaign goal. Manual progress is useful when the meaningful work cannot be measured by words alone.

The **current year** is a world reference rather than today’s real date. Records that can calculate ages use it alongside saved birth or start years. Changing it can therefore change displayed ages without rewriting the underlying records.

Targets are planning aids. Lowering or raising one does not alter writing, scenes or exports. If progress looks wrong, check whether the project type uses words, sessions or a manual measure.
