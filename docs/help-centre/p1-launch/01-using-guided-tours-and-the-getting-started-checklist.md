# Using guided tours and the Getting Started checklist

Guided tours point out key controls, while **Getting started** tracks the first useful things to do in YOW.

## The how

### Use the checklist

1. Open the **Library**.
2. Select **Getting started**.
3. Choose an available action, such as **New project**, or open the relevant area yourself.
4. Select **Dismiss** when every step is complete, or **Don't show again** to hide the checklist earlier.

### Control guided tours

1. Open the account menu and select **Account Settings**.
2. Open **Preferences**.
3. Turn **Guided tours** on or off.

During a tour, use **Next**, **Back**, **Skip tour** or the step dots. Select **Don't show tours automatically** to disable future automatic walkthroughs.

📸 SCREENSHOT: Open the Library with a new documentation account and expand **Getting started**. Show the five tasks, progress indicator and **Don't show again**. Use a disposable project so at least one task is complete.

## The why: two kinds of guidance

The checklist records broad milestones: creating a project, drafting the first scene or equivalent item, adding a character, building part of the world and exporting. A step completes when YOW can detect the matching content; ticking it is not a manual promise.

Tours are short, screen-specific walkthroughs. They may open automatically the first time you reach an area, and can also be offered by tour buttons in supported screens. Disabling tours does not remove any feature or delete progress. You can re-enable them from **Preferences**.

If a tour points to a control that is not visible, close the tour and check that the relevant project room is enabled in **Project Settings → Sections**.
