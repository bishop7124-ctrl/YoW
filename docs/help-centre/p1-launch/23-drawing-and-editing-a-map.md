# Drawing and editing a map

The Map Builder combines drawing tools, symbols, layers and editable objects on a zoomable canvas.

## The how

1. Open **Atlas** and select a map created in the new builder.
2. Choose a tool: **Select**, **Pan**, land/room shape, **Water**, **River**, **Route**, **Territory**, **Wall**, **Place**, symbols or **Label**.
3. Follow the hint above the canvas. Some tools use drag/freehand; point modes use repeated clicks followed by **Finish**.
4. Use **Select** to choose an element and edit its name, position, size, thickness or other available properties.
5. Use **Duplicate**, **Delete item**, **Send back** or **Bring forward** as needed.
6. Use **Undo**, **Redo**, zoom and **Fit** to navigate safely.
7. Open **?** for the current keyboard shortcuts.

## The why: every mark remains editable

Objects are stored as map data rather than flattened into one picture. This allows individual elements to be renamed, reshaped, moved, hidden, reordered or deleted later. Point-drawn shapes expose round points for reshaping; freehand objects favour speed.

The square grid and **Distance per square** are visual planning aids. **Changes save with your project**, but exporting editable JSON is still useful before a major redesign.

Keyboard shortcuts apply while the map has focus. Typing in a field keeps normal text behaviour, and **Esc** returns symbol placement to Select.
