# Connecting maps to Locations

Named map elements can link to existing Location records or create a new Location directly from the map.

## The how

### Link an existing Location

1. Open **Atlas** and edit a map.
2. Choose **Select**, then select a named map element.
3. In **Linked location**, choose an existing Location.
4. Select **Open location ↗** to confirm or edit the full record.

### Create a Location from a map element

1. Select an unlinked element.
2. Enter a **Name**.
3. Select **Create Location from this**.
4. Open the new Location and add its category, description, tags and image.

📸 SCREENSHOT: Select a named place symbol on a disposable map. Show **Name**, **Linked location**, **Create Location from this** or **Open location ↗**, plus the matching label on the canvas.

## The why: visual position and descriptive record

The map element stores shape and position. The Location stores the richer worldbuilding profile. Linking them lets you move between those two views without copying the Location description into the map.

Creating from the map uses the element name and starts a basic Location, typically in a general category. Complete the full profile afterwards. Renaming one side does not necessarily rewrite the other, so review both if names change.

Deleting a map element or an entire map does not delete the linked Location. Likewise, removing the Location can leave a map mark that needs relinking.
