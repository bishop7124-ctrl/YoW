# Adding project covers and header banners

Project images help identify work in the Library and give an open project its own visual identity.

## The how

1. In the **Library**, open a project card menu and choose **Edit project**.
2. In the image area, choose or upload a **Cover photo**.
3. Add a **Header banner** if the field is available.
4. Reposition or review the preview where offered.
5. Select **Save changes**.

To replace an image, choose a new file in the same field. To remove it, use the image’s remove control and save.

## The why: where images appear

The cover is the portrait-style identity used on Library cards and related project displays. The header banner is a wider image used across the open project interface. They are separate so one image does not have to serve two very different crops.

Uploaded media is compressed where supported, but it still counts towards cloud storage. Replacing or removing an image should remove the old stored object after the change completes; the storage figure may take a short time to refresh.

Use images you have permission to store. Avoid placing essential text near an edge because responsive layouts crop banners differently on narrow screens. If an upload fails, check the accepted file type, account storage allowance and connection before retrying.
