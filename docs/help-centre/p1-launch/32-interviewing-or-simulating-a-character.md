# Interviewing or simulating a character

AI Character Simulation lets you question a saved character in different exploratory interview modes.

## The how

1. Open **AI Tools → AI Character Simulation**.
2. Choose a saved **Character**.
3. Choose an **Interview mode**, such as General, Backstory, Motivation, Relationships, Secrets, Emotional state or Dialogue voice.
4. Add an optional **Timeline position**.
5. Start the session and ask a question.
6. Continue the conversation, or open **Previous sessions** to resume one.
7. Save useful answers as raw ideas.
8. Delete a session when it is no longer needed.

📸 SCREENSHOT: Open the simulation setup for a fictional character. Show the character selector, all interview modes, timeline-position field and **Previous sessions**. Do not send a request while capturing.

## The why: exploratory, not automatically canon

The simulation uses the character profile and selected project context to improvise an answer. YOW explicitly treats responses as exploratory. Saving an answer as an idea keeps it available for review without rewriting the character profile as fact.

Timeline position helps frame what the character should know or feel at a particular moment, but the model can still reveal information the character should not know. Check every response against the manuscript and lore.

Sessions use the configured provider and may create provider charges.
