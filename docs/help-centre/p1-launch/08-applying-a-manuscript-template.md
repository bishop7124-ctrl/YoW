# Applying a manuscript template

Structural templates add a ready-made set of acts, chapters and optional placeholder scenes to a manuscript.

## The how

1. Open the manuscript and choose the structure/template control.
2. In **Choose a structure**, select a template.
3. Review its preview.
4. Turn **Include chapters** on or off.
5. If chapters are included, choose whether to **Include placeholder scenes**.
6. Select the apply button.
7. If the manuscript already has structure, read the confirmation and continue only when the added items are wanted.

📸 SCREENSHOT: Open **Choose a structure** in a disposable project. Select a template and show its preview, **Include chapters**, **Include placeholder scenes** and the apply button. Keep the existing manuscript nearly empty.

## The why: templates add rather than erase

A template is a starting framework, not a writing rule. It creates named structural items appropriate to the chosen pattern, which you can rename, move or delete afterwards.

Applying a template to an existing manuscript adds the new structure. Despite the caution shown when content already exists, YOW does not silently delete the current acts, chapters or scenes. This can leave two overlapping frameworks, so review the rail first and create a backup for a valuable project.

Turning off chapters produces only the highest-level framework. Placeholder scenes provide prompts and positions but contain no finished prose. Project types use their own structural labels, so a campaign or comic may describe the levels differently from a Novel.
