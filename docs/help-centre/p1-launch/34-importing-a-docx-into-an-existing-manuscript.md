# Importing a DOCX into an existing manuscript

**Import a document** detects headings in a DOCX and appends selected structure and text to the open manuscript.

## The how

1. Open the destination manuscript.
2. Open **More** and select **Import a document**.
3. Drop a `.docx` file into **Import manuscript**, or select the area to browse.
4. Wait for **Parsing structure** to finish.
5. Review the detected word count, acts, chapters and scenes.
6. Select or clear the items you want to import.
7. Confirm the import.
8. Review the newly appended structure in the manuscript rail.

📸 SCREENSHOT: Import a short fictional DOCX with clear heading styles. Show the parsed preview, word total, nested structure, selection controls and final import button. Use a destination with one existing chapter to make the append behaviour clear.

## The why: headings guide the result

DOCX structure detection relies heavily on paragraph and heading styles. A visually large heading that is stored as ordinary body text may not become a chapter. Review the preview before importing.

The import appends; it does not replace existing acts, chapters or scenes. Repeating it can therefore create duplicates. A damaged, password-protected or unsupported document may fail before any project records are changed.

This route imports into an existing manuscript. Use **Manuscript Discovery** from the Library when the document should become a new project with candidate worldbuilding records.
