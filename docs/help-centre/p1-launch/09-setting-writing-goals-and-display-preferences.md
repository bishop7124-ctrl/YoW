# Setting writing goals and display preferences

The manuscript Inspector controls personal reading and writing presentation as well as daily and project progress goals.

## The how

### Set goals

1. Open a manuscript and select **Inspector → Progress**.
2. Set or edit the **Daily goal**.
3. Review today’s count, current streak, best streak and the last seven days.
4. Edit the available project target if required.

### Change the writing display

1. Select **Inspector → Format**.
2. Choose a **Typeface**, size and line spacing.
3. Choose **Left**, **Center** or **Justify** alignment.
4. Choose **Indent first line** or **Space between** paragraphs.
5. Turn scene metadata on or off while writing.
6. Use **Reset to defaults** to restore YOW’s standard format.

Use the manuscript zoom control and fullscreen control for temporary workspace changes.

📸 SCREENSHOT: Open **Inspector → Format** beside a fictional scene. Show typeface, size, spacing, alignment, paragraph and metadata controls. Use enough prose to make the visual changes apparent.

## The why: presentation does not rewrite prose

Format settings change how the manuscript appears in the editor. They do not insert spaces into every paragraph or permanently rewrite the scene text. Export layouts can use their own document or PDF styling.

The daily goal counts recorded word additions by local calendar day. A day with older imported text may show no new words, and changing the target does not retroactively rewrite earlier goal results. Streaks are motivational summaries rather than billing or access requirements.

Project targets describe the whole manuscript or campaign. Daily goals describe current writing habits. Use them together when helpful, or leave either unset.
