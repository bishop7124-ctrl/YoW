# Planning your story with the Outline

The Outline provides a planning view of the project’s nested story structure without opening each scene in the manuscript editor.

## The how

1. Open the project and select **Outline**.
2. Use the add controls to create a top-level item, nested section or writing item.
3. Select an item to edit its title and planning details.
4. Drag the handle to reorder it, or use the up and down controls.
5. Use the parent selector to move a nested item into another parent.
6. Review **Unplaced** items and assign them when ready.

The labels vary by project type: a Novel uses acts, chapters and scenes; campaigns and comics use their own structure.

## The why: structure without prose distraction

Outline and manuscript structure describe the same project items from different working perspectives. Moving a scene in the Outline therefore changes where that scene appears in the manuscript; it does not create a separate planning copy.

Unplaced items are valid records that do not currently belong to a parent. This is useful when capturing a scene before deciding where it belongs. Deleting a structural item can affect its children, so read the confirmation and create a backup before a large reorganisation.
