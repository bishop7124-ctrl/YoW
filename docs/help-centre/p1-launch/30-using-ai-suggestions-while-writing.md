# Using AI suggestions while writing

The manuscript AI panel can answer a custom request, run quick actions or rewrite selected or focused scene text.

## The how

1. Open a manuscript, focus a scene and select **AI**.
2. Highlight text if the request should apply only to a passage; otherwise YOW uses the focused scene context.
3. Enter a request under **Ask AI**, or choose a **Quick action**.
4. For a rewrite, choose point of view or tense where offered.
5. Select generate, or use **Ctrl+Enter** from the request box.
6. Use **Stop** to interrupt generation.
7. Review the result, then choose **Replace**, **Append**, **Copy** or **Discard**.
8. For a long rewrite, continue until every chunk finishes before inserting it.

## The why: review before changing prose

Selected text narrows the task; without a selection, YOW can use the focused scene. Project records may also be included as context. The provider can still misunderstand tone, canon or intent.

Long rewrites are split into chunks to stay within model limits. Replacing before all chunks complete is blocked because it would insert only part of the rewrite. **Stop** keeps the current response but may leave it incomplete.

Copying does not alter the scene. Replace and append do, so confirm the normal save indicator and use version history if you later need the earlier text.
