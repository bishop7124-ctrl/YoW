# Adding scene details and manuscript notes

Scene details describe a scene without putting planning information into the prose, while anchored notes keep reminders beside a precise writing position.

## The how

### Edit scene details

1. Open the manuscript and focus a scene.
2. Open **Inspector** and select **Scene**.
3. Edit the **Title**, **Status**, **Point of view**, **Location** and **Summary**.
4. Leave the field or continue writing; changes save automatically.

Select a chip under **In this scene** to preview a detected linked record, then choose **Open full entry** when available.

### Add a manuscript note

1. Place the cursor at the relevant point in a focused scene.
2. Use the note **+** control beside the cursor.
3. Open **Inspector → Notes**.
4. Give the note a title and write the reminder.
5. Delete the note with **×** when it is no longer needed.

📸 SCREENSHOT: Focus a disposable scene and open **Inspector → Scene**. Show status buttons, POV, location, summary and **In this scene** chips. Use fictional names that already exist as project records.

## The why: metadata versus prose

POV, location, summary and status make scenes easier to scan and analyse without appearing in the manuscript export as story text. POV and location accept saved names and can connect the writing workspace with full character or location records.

Notes are private planning annotations. Anchoring one to the cursor helps preserve what a reminder refers to as the scene grows, but major rewrites can make an old position less exact. Notes belong to the scene and are separate from tracked revisions and version history.
