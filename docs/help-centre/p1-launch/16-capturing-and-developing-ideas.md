# Capturing and developing ideas

The Ideas Board stores fragments, favourites and developing concepts without forcing them into a finished project record.

## The how

1. Open **Ideas**.
2. Use the quick-capture control or select **New idea**.
3. Add a title and description.
4. Choose a status, add comma-separated tags and mark **Favourite** if useful.
5. Search for project records to add under **Linked to**.
6. Select **Save idea**.

On the board, drag an idea between status columns. Open it to edit, delete, choose **Save & Convert**, or choose **Save & AI expand** when AI access is configured.

## The why: a low-commitment workspace

Statuses describe how developed an idea is, while tags and favourites help retrieve it. Moving a card changes only its status. Links connect the idea to existing characters, places, lore, events or chapters without copying their content.

AI expansion sends relevant idea and project context to the configured provider and returns exploratory material. It does not make the result canon or automatically replace the idea.

In a series that shares Ideas, deletion may offer **Delete from this project** or **Delete from all synced projects**. Read that choice carefully.
