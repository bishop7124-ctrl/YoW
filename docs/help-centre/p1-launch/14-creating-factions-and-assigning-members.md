# Creating factions and assigning members

Factions collect organisations, allegiances and their character memberships in one project room.

## The how

### Create a faction

1. Open **Factions**.
2. Select **New Faction**.
3. Add a **Faction Name**, description and optional logo.
4. Save the faction.

### Add or change members

1. Select a faction.
2. In its members area, choose a project character.
3. Add a role such as “captain”, “member” or “spy”.
4. Save or confirm the membership.

Use the sort selector to arrange factions by name or member count. Use **Edit** to change a profile and **Delete** to remove a faction.

## The why: organisations and memberships

A faction is its own record, while membership connects existing characters to it. Opening or removing a membership does not delete the character. Deleting a faction removes the organisation record and its membership links, so review linked characters first.

Faction logos can be uploaded or created through YOW’s logo tools where available and may count towards storage when saved as user media. Roles are free-form, allowing one character to belong to different factions in different capacities.

Factions can also be discovered during manuscript import and linked from lore or other project areas.
