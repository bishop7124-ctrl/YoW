# Searching, replacing and jumping between scenes

Manuscript search finds text across every scene in the open project and can replace matches in one scene or throughout the project.

## The how

1. Open the manuscript.
2. Open **Search Manuscript** from the manuscript tools, or use the displayed search shortcut.
3. Enter a search term.
4. Turn on **Match case** or **Whole word** if needed.
5. Select a result or its **Go to scene** control to open that scene.

To replace text:

1. Select the replace toggle.
2. Enter **Replace with** text.
3. Choose replace for a particular scene or **Replace all** for the project.
4. Use **Undo** in the confirmation message immediately if the result is not what you wanted.

## The why: project-wide changes need care

Results show a short excerpt around each match, making it easier to distinguish dialogue from names or planning text. **Match case** separates forms such as “Ash” and “ash”; **Whole word** stops a short term matching inside a longer word.

Replacement applies immediately to the affected scene content. The on-screen undo is intended as a short recovery route, not a permanent revision archive. Before a large rename, create a project backup or confirm that scene version history contains a suitable recovery point.

Search covers manuscript scene text, not every character, lore or schedule field in the project.
