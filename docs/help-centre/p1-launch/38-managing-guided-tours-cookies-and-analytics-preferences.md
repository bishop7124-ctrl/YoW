# Managing guided tours, cookies and analytics preferences

Preferences control optional walkthroughs and which non-essential browser storage or analytics YOW may use.

## The how

1. Open **Account Settings → Preferences**.
2. Turn **Guided tours** on or off.
3. Review the cookie choices:

   - **Essential** — authentication and security; always active
   - **Preferences** — theme, font and interface choices between sessions
   - **Analytics** — anonymous usage information used to improve YOW

4. Change the optional choices and save.
5. Wait for the **Saved** confirmation before closing Settings.

📸 SCREENSHOT: Open **Account Settings → Preferences**. Show **Guided tours**, all three cookie rows, the disabled Essential control and the save confirmation. Use a documentation account.

## The why: essential and optional storage

Essential storage supports sign-in and security and cannot be disabled through this panel. Preference storage helps YOW remember interface choices. Analytics is optional and is described as anonymous usage data.

Turning off Preferences may mean some display or tour choices are not remembered in the same way between visits. Turning off Analytics should not remove product features. Guided tours are a separate interface preference and can be re-enabled later.

Changing these settings affects future use; it does not delete project writing or account records.
