# Editing your writer profile

Your writer profile stores the name and creative identity associated with your YOW account.

## The how

1. Open the account menu and select **Account Settings**.
2. Open **Profile**.
3. Edit your **Name**, **Writing alias**, **Bio** and **Website**.
4. Enter an **Avatar URL** or select **Upload image** for a PNG, JPG, WebP or GIF.
5. Save the profile.

To replace an uploaded avatar, upload another image. Use the image removal control if you want to return to the default avatar.

## The why: account details and local changes

The writing alias can hold a pen name or studio name without changing the account email. Website and bio are optional profile details; they do not alter project authorship metadata automatically.

Uploaded images are compressed before saving and count towards storage. A remote avatar URL depends on the remote host continuing to serve the image.

When Lifetime cloud hosting is inactive in the desktop app, YOW can save profile changes on that device. Those local changes do not automatically appear on other devices until eligible cloud syncing resumes and reconciliation completes.
