# Finding plot holes, lore conflicts and style inconsistencies

AI Tools can inspect project context for possible plot, lore and style issues that deserve a human review.

## The how

1. Configure AI and open a project.
2. Open **AI Tools**.
3. Choose **Plot Holes**, **Lore Conflicts** or **Style Analysis**.
4. Select the available scope or filters.
5. Run the analysis and wait for it to finish.
6. Filter or open individual findings.
7. Follow evidence links back to the relevant scene or project record.
8. Save a useful finding to the project when that option is offered, or dismiss it from your working list.

📸 SCREENSHOT: Open a completed analysis in a disposable project. Show the selected tool, filters, two findings with severity/evidence and a navigation or save control. Use deliberately invented contradictions.

## The why: findings are prompts, not verdicts

Each tool asks a different question. Plot analysis looks for gaps or unsupported turns; lore analysis compares saved facts; style analysis looks for inconsistency in the writing sample. Results depend on the context YOW can send and may miss implied information.

A finding can be a false positive, especially with unreliable narrators, deliberate ambiguity or records that have not been updated. Open the evidence and decide whether the project or the finding needs changing.

Analysis uses the configured third-party provider and may consume billable tokens. Large manuscripts can be covered in portions rather than one unlimited request.
