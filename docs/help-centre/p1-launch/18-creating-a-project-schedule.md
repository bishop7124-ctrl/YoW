# Creating a project schedule

The Schedule plans tasks or in-world appointments on a month grid or chronological list.

## The how

1. Open **Schedule**.
2. Select **Add event**, or select a day on the month grid.
3. Enter a title, year, month, day and duration.
4. Choose a category, add a description and comma-separated tags, and link characters or locations if needed.
5. Save the event.
6. Select **month** or **list** to change views.
7. In month view, drag an event to move it or drag its end handle to resize its duration.
8. Select an event to view, edit or delete it.

📸 SCREENSHOT: Open a custom Schedule month containing three categories and one multi-day event. Show **month/list**, **Calendar settings**, **Add event**, the move hint and resize handle.

## The why: practical planning on a calendar

Schedule is designed for dated plans that benefit from a calendar grid: writing tasks, production milestones, sessions or events within a custom project calendar. Duration counts calendar days and can cross week rows.

Dragging updates the event date; resizing updates its duration. Linked characters and locations remain intact if the schedule event is deleted.

The Schedule calendar can use invented month and weekday names. Its dates do not need to match the Timeline or World History unless you deliberately use the same convention.
