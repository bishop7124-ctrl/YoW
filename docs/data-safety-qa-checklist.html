How To Run This Checklist

Use a throwaway account unless the item explicitly says to verify a production account. Capture the exact date, account, environment, project name, browser/app version, and exported backup file name in notes. A route only passes when the saved data survives refresh, navigation, sign-out/sign-in, device transition where relevant, export, restore, and deletion cleanup expectations.

  1. Create a baseline export before destructive tests. Keep one ZIP plus at least one readable export where available.
  2. Run each item exactly as written. Do not mark Pass if you only inspected code or partially tested the route.
  3. For every Fail, add reproduction steps, expected result, actual result, affected account/project, screenshots or console details, and whether user data was recoverable from export, cloud, local vault, or browser storage.
  4. After a fix, move the item to Retest, rerun the full route, and only then mark Pass.
  5. Export this checklist at the end of every session and attach it to the roadmap or QA evidence.
