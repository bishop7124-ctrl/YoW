# DRAFT — How to organise a fantasy world (NOT PUBLISHED — needs owner review and your own examples)

Target URL: /guides/organise-a-fantasy-world/ · Reader: new fantasy author · Intent: "how to organise worldbuilding notes"

**Short answer (opens the page):** Start with what your story touches. Record the people, places, history and rules that appear on the page, link them to each other, and add depth only when a scene needs it.

## Steps
1. **List what the story needs, not everything.** Cast, key places, one or two systems (magic, politics), and a rough history of events that cause the plot.
2. **One home per fact.** Choose a single place for each detail (character, location, lore entry) so it never exists in two versions.
3. **Give places a hierarchy.** World → region → settlement → building. Name them early; rename in one place.
4. **Write the timeline before the lore.** A dated list of events exposes contradictions faster than prose entries.
5. **Link, don't repeat.** A character's birthplace should point to the location entry, not copy it.
6. **Track changes across drafts.** Note when a fact changes and which scenes it affects.
7. **Keep lore out of the prose.** Use notes for the full history; reveal only what the scene needs.
