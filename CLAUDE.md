# Project Instructions

## Roadmap Discipline

Use [docs/ROADMAP.md](docs/ROADMAP.md) as the single planning document and follow its Agent Instructions section.

## Branch Discipline

Do all work — across unrelated tasks, bug fixes, and backlog items alike — on the single branch already checked out for the session (or the one the task explicitly names). Do not create additional feature/task/QA branches, and do not spin up worktrees on new branches, unless the user explicitly asks for a separate branch for that specific piece of work.
